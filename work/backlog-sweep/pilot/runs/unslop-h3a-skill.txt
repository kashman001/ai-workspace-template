# Introducing tidyctl 2.0

tidyctl 2.0 is out. Many users have told us tidyctl is an essential part of their workflow, and this release changes a lot about how it works.

## Performance

On a 10,000-file repository, a full run now takes 15 seconds instead of 25, a 40% improvement. The `--fast` flag has been removed because fast mode is now the default.

## Configuration

`tidy.toml` replaces the legacy `.tidyrc` file (INI format). To convert your existing file, run the new `tidyctl migrate-config` command.

## Compatibility notes

- **Python support.** Python 3.9 is no longer supported. tidyctl now requires Python 3.10 or newer.
- **Deprecations.** The `tidyctl clean --all` command is deprecated. It prints a warning in 2.0 and will be removed in 2.1.

## What's next

We'd like to hear what you build with tidyctl 2.0. Happy tidying!
