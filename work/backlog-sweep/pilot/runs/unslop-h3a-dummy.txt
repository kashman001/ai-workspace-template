# Tidyctl 2.0

Tidyctl 2.0 is out. Many of you have told us tidyctl is a regular part of your workflow, and this release changes a lot under the hood.

## Performance

On a 10,000-file repository, a full run now takes 15 seconds instead of 25, a 40% improvement thanks to the new engine. Because fast mode is now the default, the `--fast` flag has been removed.

## Configuration

The legacy `.tidyrc` file (INI format) has been replaced by `tidy.toml`. To help you switch, the new `tidyctl migrate-config` command converts your existing file automatically.

## Compatibility notes

- **Python support:** Python 3.9 is no longer supported. Tidyctl now requires Python 3.10 or newer.
- **Deprecations:** `tidyctl clean --all` is deprecated. It prints a warning in 2.0 and will be removed in 2.1.

We're looking forward to seeing what you build with 2.0. Happy tidying!
