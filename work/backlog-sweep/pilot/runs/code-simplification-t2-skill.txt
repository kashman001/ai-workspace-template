```javascript
function discount(order) {
  let rate = 0;
  if (order.total > 100) rate = 0.1;
  else if (order.total > 50) rate = 0.05;

  if (order.isMember === true) rate += 0.05;

  return order.total * (1 - Math.min(rate, 0.15));
}
```

Note: I renamed `d` to `rate`, dropped the redundant `else` and temp variable, and replaced the cap `if` with `Math.min`, keeping the strict `isMember === true` check.

One caveat: `total - total * d` and `total * (1 - d)` can differ in the last floating-point digit, so if exact bit-for-bit output matters, keep the original `order.total - order.total * rate` form.
