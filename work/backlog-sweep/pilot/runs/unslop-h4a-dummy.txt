## Getting Started With Ratelimitr 🚦

Ratelimitr is a lightweight rate-limiting library for Go. It helps you protect your services without needing heavyweight infrastructure.

### Installation

You'll need Go 1.22 or later. Then run:

```
go get github.com/example/ratelimitr@v0.9.0
```

### Key Features

- **Algorithms:** Token bucket and sliding window are both supported, so you can pick whichever suits your needs.
- **Storage:** Limits can be kept in memory or in Redis (version 6 or newer), which lets you scale across distributed deployments.
- **Performance:** Each check takes roughly 80 nanoseconds in memory.

Many developers have found that Ratelimitr makes their APIs more resilient. The default limit is 100 requests per minute per key, which you can change with `ratelimitr.WithLimit`. Happy coding!
