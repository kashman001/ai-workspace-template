# tidyctl 2.0

tidyctl 2.0 is out. It has a new engine, a new config format, and a few breaking changes, so please read the notes below before upgrading.

## Faster runs

On a 10,000-file repository, a full run now takes 15 seconds instead of 25, a 40% improvement. Fast mode is now the default behavior, so we've removed the `--fast` flag.

## New config format

The legacy `.tidyrc` file (INI format) has been replaced by `tidy.toml`. To help you switch, the new `tidyctl migrate-config` command converts your existing file automatically.

## Compatibility notes

- **Python support:** Python 3.9 is no longer supported. tidyctl now requires Python 3.10 or newer.
- **Deprecations:** `tidyctl clean --all` is deprecated. It prints a warning in 2.0 and will be removed in 2.1.

Thanks for using tidyctl. Happy tidying!
