# Tidyctl 2.0 release

Tidyctl 2.0 is out. Many of you have told us tidyctl is part of your daily workflow, and this release changes a lot.

## Performance

On a 10,000-file repository, a full run now takes 15 seconds instead of 25, a 40% improvement from the new engine. The `--fast` flag is gone because fast mode is now the default.

## Configuration

The legacy `.tidyrc` file (INI format) is replaced by `tidy.toml`. To convert your existing file, run the new `tidyctl migrate-config` command.

## Compatibility notes

- Python 3.9 support has been dropped. Tidyctl now requires Python 3.10 or newer.
- The `tidyctl clean --all` command is deprecated. It prints a warning in 2.0 and will be removed in 2.1.

Happy tidying!
