```js
function discount({ total, isMember }) {
  const base = total > 100 ? 0.1 : total > 50 ? 0.05 : 0;
  const rate = Math.min(base + (isMember === true ? 0.05 : 0), 0.15);
  return total - total * rate;
}
```

I replaced the mutable `d` and if/else chains with a nested ternary for the tier rate, a single `Math.min` cap, and a direct return, keeping the strict `isMember === true` check.
