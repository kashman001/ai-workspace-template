## Getting Started With Ratelimitr 🚦

Ratelimitr serves as a lightweight yet powerful rate-limiting library for Go — empowering developers to protect their services seamlessly, without the overhead of heavyweight infrastructure. It's not just a limiter, but a comprehensive toolkit for traffic management.

### Installation

In order to get started, it is important to note that you will need Go 1.22 or later. Simply run:

```
go get github.com/example/ratelimitr@v0.9.0
```

### Key Features

- **Algorithms:** Algorithms are flexible — both token bucket and sliding window are supported, ensuring that you can choose the strategy that best fits your needs.
- **Storage:** Storage is pluggable: limits can be kept in memory or in Redis (version 6 or newer), fostering scalability across distributed deployments.
- **Performance:** Performance is exceptional, with each check taking roughly 80 nanoseconds in memory, showcasing the library's efficiency.

Many developers have found that Ratelimitr dramatically enhances their API's resilience. Note that the default limit is 100 requests per minute per key, which can be changed via `ratelimitr.WithLimit`. Happy coding!
