# Introducing Tidyctl 2.0: The Future Of Repository Hygiene 🎉

We're thrilled to announce tidyctl 2.0 — a release that doesn't just iterate on what came before, but reimagines the entire experience from the ground up. Many users have told us that tidyctl has become an indispensable part of their workflow, and this release stands as our boldest step yet.

## Blazing Fast Performance ⚡

Speed was at the heart of this release. On a 10,000-file repository, a full run now takes 15 seconds instead of 25 — a remarkable 40% improvement, showcasing the power of our new engine. As a result, the `--fast` flag has been removed, since fast mode is now simply the default behavior, ensuring that every user benefits automatically.

## A Modern Configuration Experience 🛠️

Configuration has been thoughtfully reimagined. The legacy `.tidyrc` file (INI format) is replaced by `tidy.toml` — a cleaner, more expressive, and more intuitive format. To make the transition seamless, the new `tidyctl migrate-config` command serves as a bridge, converting your existing file automatically.

## Important Compatibility Notes ⚠️

- **Python Support:** Python 3.9 support has been dropped; tidyctl now requires Python 3.10 or newer, reflecting our commitment to modern tooling.
- **Deprecations:** The `tidyctl clean --all` command is now deprecated — it will print a warning in 2.0 and will be fully removed in 2.1.

## Looking Ahead 🌟

This is just the beginning of an exciting journey. We can't wait to see what you build with tidyctl 2.0. Happy tidying!
