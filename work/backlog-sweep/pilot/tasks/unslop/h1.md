## 🚀 Overview: A New Era For Invoice Sync

This PR introduces a pivotal shift in how invoice-sync talks to the billing provider — moving away from polling and embracing webhooks, ensuring that our integration is not just faster, but fundamentally more resilient. It serves as the foundation for the real-time billing roadmap, showcasing what a modern, event-driven architecture can deliver.

## ✨ Key Highlights

- **Efficiency:** Efficiency is dramatically enhanced — daily API calls drop from roughly 12,000 to around 400, underscoring the value of an event-driven approach.
- **Reliability:** Reliability is improved, since each webhook delivery is retried up to 3 times, fostering a more robust and seamless experience.
- **Data Model:** The data model is extended — migration 0042 adds a `webhook_events` table, which stands as the single source of truth for every incoming event.
- **Safety:** Safety is crucial here: the whole feature sits behind the `INVOICE_WEBHOOKS` flag, which is off by default.

## 🧪 Testing And Validation

The change was carefully validated in staging over a period of 5 days, and it is widely believed by the team that it is ready. Rollback is effortless: simply flip the flag off — no redeploy is needed.
