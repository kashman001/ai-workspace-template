# context-memory-eval — Evaluate this workspace against context- and memory-engineering concepts

Governing skill(s): none.

**Start here:** `next-session.md` (catch-up launcher) → `handoff.md`
(session ledger, top block).

## What this is

A check of this template against an outside framework for agent context
and memory engineering: the article "Autonomous Agent Architecture: Unifying
Context Engineering and Memory Engineering" by @marfinxx on X (2026-08-14).
`source-notes.md` sums up the article's concepts. `eval.md` scores the
workspace against each one, with the evidence on disk, and lists the gaps
and recommendations. The deliverable is an assessment. Any template change
it suggests goes through the backlog only after the user picks it.

## Success criteria

- Every concept in `source-notes.md` has a verdict in `eval.md`
  (Strong / Partial / Gap / Non-goal) with at least one on-disk evidence path.
- Recommendations are ranked and each says whether it is a doc change, a
  script change, or a deliberate non-goal.
- The user has reviewed the recommendations. Each accepted one is carded in
  `docs/template-workspace-backlog.html`, and each rejected one is noted
  in `decisions.md`.

## Files

- `next-session.md` — forward launcher (what to do next). REPLACED each rollover.
- `handoff.md` — session ledger (what happened). APPEND newest-on-top; archive
  to `handoff-archive.md` when it exceeds the two most recent sessions.
- `source-notes.md` — the article's concepts, paraphrased, plus source URL.
- `eval.md` — concept-by-concept scorecard, gaps, ranked recommendations.
- `decisions.md` — which recommendations were accepted, and why 5 was deferred.
