# DevEx Review — persona-based developer-experience review of this template workspace

Governing skill(s): none.

**Start here:** `next-session.md` (catch-up launcher) → `handoff.md`
(session ledger, top block).

## What this is

A Developer Experience review of the ai-workspace-template itself, run via
persona agents (developer, product manager, QA engineer) each doing a
cold-start walkthrough of the template across the development lifecycle.
Goal: collect honest adoption feedback, synthesize it into a findings
report, and feed actionable items into the template backlog
(`docs/template-workspace-backlog.html`).

## Files

- `next-session.md` — forward launcher (what to do next). REPLACED each rollover.
- `handoff.md` — session ledger (what happened). APPEND newest-on-top; archive
  to `handoff-archive.md` when it exceeds the two most recent sessions.
- `findings/` — raw persona reports and the synthesized review (added as they land).
