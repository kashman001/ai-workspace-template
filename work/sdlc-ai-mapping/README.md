## What this is

An analysis effort to map the end-to-end software development and maintenance
lifecycle (SDLC) for a software product — from idea through build, release,
operations, and maintenance — and then overlay two lenses on that map: where
AI agents genuinely help at each stage, and where this workspace template
specifically supports that stage. The output is a durable map/document, built
up through conversation, that can later drive template improvements or new
capabilities.

## Success criteria

- A written SDLC map exists in this directory covering the full lifecycle
  (not just the coding phase): discovery/requirements, design, implementation,
  review/QA, release, operations, and maintenance.
- For each stage, the map states (a) where AI helps and how, and (b) which
  template capability (skill, doc, convention) supports it — or explicitly
  marks a gap.
- The gaps are captured as a candidate list (potential backlog items or new
  work), agreed with the user.

## Files

- `next-session.md` — forward launcher (what to do next). REPLACED each rollover.
- `handoff.md` — session ledger (what happened). APPEND newest-on-top; archive
  to `handoff-archive.md` when it exceeds the two most recent sessions.
- `sdlc-map.md` — the SDLC map itself (with the template overlay).
- `sdlc-map-standalone.md` — workspace-independent version of the map (no
  template overlay, no gap register; three views — phases, graph,
  artifacts) — for sharing/discussing AI in the SDLC outside this
  workspace. Published artifact:
  https://claude.ai/code/artifact/f86be94e-2362-4342-bddf-0105f395a204
  — republish only **with that URL as `url`** to avoid a duplicate.
