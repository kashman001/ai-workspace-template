Proposal for the team

Measure the context budget, don't guess it

Agent sessions degrade quietly past 150K tokens. We can catch that from disk and hand off on purpose.

The numbers

Two lines, one rule

120K

WARN: finish the unit, ask about rolling over

150K

STOP: finish the atomic step, roll over with no ask

~200K

Claude Code auto-compact; STOP must sit below it

±25%

error of the fallback estimate, absorbed by the 30K margin

Why it works

Three ideas carry it

  1. The model can't see its own usage. The number comes from the runtime's session file on disk.
  2. WARN asks, STOP goes. Humans decide early; the system acts once quality is at risk.
  3. The dying session writes the handoff. Only it holds the state that must reach disk.
  4. Three commands are the whole daily loop. Register, record, roll over.

Cost to the team

Almost nothing to adopt

Automatic

Registration runs from a hook in Claude Code and Copilot VS Code.

One habit

Run record at each work-unit boundary and obey the exit code.

One knob

ROLLOVER_RELAUNCH: off, manual (default) or auto.
